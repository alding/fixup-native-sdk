# 组件配置边界

FixupModule 的服务端配置是“数据驱动的内置组件选择”，不是远程代码执行系统。

## 一、允许的配置内容

配置可以包含以下数据：

- 组件类型和展示顺序
- 组件 ID
- 标题、描述、图片和颜色
- 间距、圆角、尺寸和背景配置
- 商品、话题、直播、公告等业务数据
- 已实现 `LinkType` 的跳转参数
- 页面背景、主题色和灰度状态

组件数据由 `FixupComponentModel` 解码，渲染由 SDK 内置的 `FixupComponentFactory` 和 SwiftUI/UIKit 视图完成。

## 二、处理未知值

服务端可能在版本升级期间先返回 SDK 尚未支持的组件或动作。宿主应遵循以下规则：

1. 未知组件不阻塞其他组件渲染。
2. 未知动作不打开任意 URL，不调用任意外部应用。
3. 数据解析失败时展示空状态或错误提示。
4. 新的原生能力必须通过 SDK 发版和宿主审核后才能使用。

## 三、组件能力范围

当前 SDK 包含的主要内置组件类别：

- 搜索和导航
- 轮播、图片广告和公告
- 直播信息、话题、视频和专属直播
- 商品、商品分类和积分活动
- 热区、组合组件和内容聚合
- 代理绑定、悬浮导航和客服二维码
- 页面背景、主题色和灰度展示

具体类型以 `FixupComponentType` 和当前 SDK 版本公开文档为准。服务端不应把未发布的类型发送给旧版本宿主。

## 四、链接安全

组件中的链接只应进入 SDK 或宿主已经实现的白名单路径。宿主负责：

- 校验 WebView 地址的域名和协议
- 决定是否允许打开小程序
- 决定是否允许跳转直播详情
- 处理登录失效和外部能力不可用

SDK 不应把配置字符串当作代码执行，也不应把任意远程 URL 当作新的 App 功能。
